# Модуль Category и Product
Это классы для представления товара и для представления категории товаров

## Особенности
* Автоматический подсчет количества категорий и товаров через атрибуты класса

* Поддержка namespace packages (без обязательных __init__.py)

* Полная аннотация типов

* Тесты покрывают инициализацию и 

### Класс `Smartphone` (наследник `Product`)
Представляет смартфон с расширенными характеристиками.

**Дополнительные атрибуты:**
* `efficiency` (str) - производительность (Высокая, Средняя, Максимальная)
* `model` (str) - модель смартфона
* `memory` (int) - объём встроенной памяти в ГБ
* `color` (str) - цвет смартфона

### Класс `LawnGrass` (наследник `Product`)
Представляет газонную траву с расширенными характеристиками.

**Дополнительные атрибуты:**
* `country` (str) - страна-производитель
* `germination_period` (int) - срок прорастания в днях
* `color` (str) - цвет травы

### Абстрактный базовый класс `BaseProduct`
Определяет интерфейс для всех продуктов в системе.

**Абстрактные методы и свойства:**
* `__init__(name, description, price, quantity)` - конструктор
* `@property price` - геттер для получения цены
* `@price.setter` - сеттер для установки цены
* `@property total_cost` - общая стоимость товара (price × quantity)
* `__str__()` - строковое представление продукта
* `__add__(other)` - сложение товаров (только одного класса!)
* `__radd__(other)` - поддержка функции `sum()`
* `@classmethod new_product(product_data: dict)` - создание продукта из словаря

### Миксин `LogMixin`
Обеспечивает автоматическое логирование создания всех объектов-продуктов.

**Функциональность:**
* При создании любого продукта выводит в консоль информацию о классе и параметрах
* Не нарушает основную функциональность продуктов
* Работает через множественное наследование
