# Модуль Category и Product
Это классы для представления товара и для представления категории товаров

## Особенности
* Автоматический подсчет количества категорий и товаров через атрибуты класса

* Поддержка namespace packages (без обязательных __init__.py)

* Полная аннотация типов

* Тесты покрывают инициализацию и 

### Класс `Smartphone` (наследник `Product`)
Представляет смартфон с расширенными характеристиками.

**Дополнительные атрибуты:**
* `efficiency` (str) - производительность (Высокая, Средняя, Максимальная)
* `model` (str) - модель смартфона
* `memory` (int) - объём встроенной памяти в ГБ
* `color` (str) - цвет смартфона

### Класс `LawnGrass` (наследник `Product`)
Представляет газонную траву с расширенными характеристиками.

**Дополнительные атрибуты:**
* `country` (str) - страна-производитель
* `germination_period` (int) - срок прорастания в днях
* `color` (str) - цвет травы

### Тестирование
Модули сопровождаются набором тестов, которые можно проверить командами:
* Запуск всех тестов `uv run pytest`
* Запуск с отчетом о покрытии `uv run pytest --cov=tests --cov-report=html`
