# Модуль Category и Product
Это классы для представления товара и для представления категории товаров

## Особенности
* Автоматический подсчет количества категорий и товаров через атрибуты класса

* Поддержка namespace packages (без обязательных __init__.py)

* Полная аннотация типов

* Тесты покрывают инициализацию и подсчеты

### Тестирование
Модули сопровождаются набором тестов, которые можно проверить командами:
* Запуск всех тестов `uv run pytest`
* Запуск с отчетом о покрытии `uv run pytest --cov=tests --cov-report=html`
